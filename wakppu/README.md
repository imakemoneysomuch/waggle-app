# 왁뿌볼 부수기 (시범판)

한 손으로 만져서 부수는 안드로이드용 촉감 시뮬레이터. 설치 없이 브라우저로
바로 열리고, 홈 화면에 추가하면 전체화면 앱처럼 뜬다(PWA).

배포된 사이트 기준 경로: `https://<사이트 주소>/wakppu/`

## 어떻게 노는지

화면의 볼을 손가락으로 누르거나 문지르면 부서진다. 부서지는 **정도**는 두
가지로 정해진다.

- **닿아있는 범위** — 손가락을 넓게 댈수록(접촉 반경이 클수록) 손상이 미치는
  범위와 세기가 같이 커진다. 손톱 끝으로 콕 찌르는 것과 엄지를 꾹 눌러 뭉개는
  게 다르게 동작한다.
- **닿아있는 시간** — 누르고 있는 동안 계속 손상이 쌓인다. 오래 누를수록 깊게
  들어간다.

상단 바가 남은 내구도, 그 아래 줄이 지금 감지된 접촉 지름(mm 환산)·압력·누른
시간이다. 실제 기기에서 손가락을 굴려보면 숫자가 같이 움직인다.

## 재질 3종

| | 느낌 | 부서지는 방식 | 소리 | 진동 |
|---|---|---|---|---|
| 🫓 반죽 | 말랑, 잘 안 돌아옴 | 눌린 자국이 그대로 굳고 늘어지다 뭉개짐 | 젖은 "철퍽" (저역 + 대역 노이즈 스윕) | 길고 뜸한 펄스 |
| 🍪 크런치 | 단단, 문턱 넘어야 깨짐 | 실금 → 쩍 갈라짐 → 산산조각 | 마른 알갱이 파열 + "쩍" 트랜지언트 | 짧고 불규칙한 펄스 |
| 🧊 슬러시 | 물러서 흘러내림 | 젖은 자국 남기며 주저앉음 | 얼음 사각사각 + 물기 저역 | 아주 짧고 촘촘한 펄스 |

## 안에서 무슨 일이 벌어지나

- **물리** — 볼은 정점 60개짜리 소프트바디 링이다. 이웃 스프링 + 내부 압력(면적
  보존) + 원래 모양으로 돌아가려는 힘으로 물컹거리고, 손가락은 그 자리의 재료를
  옆으로 밀어낸다. 손상된 구간은 결합과 형태 기억을 잃어서 거기부터 무너진다.
  반죽·슬러시는 눌린 모양이 굳는 소성 변형이 커서 점점 퍼진다.
- **소리** — 외부 음원 파일이 없다. 전부 WebAudio로 그 자리에서 합성한다.
  노이즈 알갱이를 몇 개, 어떤 필터로, 얼마나 짧게 터뜨리는지가 재질 차이다.
- **진동** — Vibration API는 세기 조절이 안 되고 길이만 준다. 그래서 펄스
  길이와 간격을 재질별로 다르게 잡아 촘촘함/묵직함의 차이를 낸다. 첫 터치
  이후에만 동작하고, iOS 사파리는 이 API가 없어서 안드로이드 크롬 기준이다.

## 확인한 것

헤드리스 크롬에서 실제 터치 이벤트(접촉 반경·압력 포함)를 넣어 돌려봤다.

- 좁게(⌀6mm) 1.2초 → 내구도 88~96% (거의 안 부서짐)
- 보통(⌀12mm) 2.0초 → 내구도 48~65%
- 넓게(⌀18mm) 문지르기 → 크런치 1.8초 / 슬러시 2.5초 / 반죽 3.3초에 파괴
- 콘솔 에러 없음, 소리 6종·진동 패턴 전부 예외 없이 실행됨

## 참고

이 폴더는 기존 와글와글 베이크샵 앱과 완전히 분리돼 있다(자체 manifest,
자체 서비스워커, `/wakppu/` 경로만 가로챔). 다만 저장소가 빌드 산출물을 통째로
덮어쓰는 방식으로 배포된다면, 배포 파이프라인에 이 폴더를 함께 올리도록
넣어줘야 한다.
